⚙️ Yönetim Paneli Bağlı değil

GitHub bağlantısı

Panel, kampanya ve çekiliş ayarlarını sitenin GitHub deposuna kaydeder. Bunun için bir kerelik bir anahtar (token) gerekir.

Token nasıl alınır? (adım adım)
  1. github.com'a giriş yap, sağ üstte profil resmine tıkla → Settings.
  2. Sol menünün en altında Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Token name: yonetim-paneli · Expiration: 90 gün.
  4. Repository access: Only select repositories seç, sitenin deposunu (örn. Piksel30.github.io) ekle.
  5. Permissions → Repository permissions → Contents: Read and write yap.
  6. Generate token'a bas, çıkan kodu kopyala (bir daha gösterilmez) ve aşağıya yapıştır.

Token bir şifre gibidir: kimseyle paylaşma, ekran görüntüsüne alma. Süresi dolunca aynı adımlarla yenisini al.

Kampanya

Sitenin üstünde şerit olarak görünür, sepette indirim otomatik uygulanır.

Önizleme

Çekiliş

1) Çekilişi sitede duyur → 2) katılımcıları topla → 3) aşağıdan adil şekilde kazananı seç.

1) Çekiliş duyurusu (sitede kart olarak görünür)

Katılmak isteyenler butona basınca WhatsApp'ında "çekilişe katılmak istiyorum" mesajı + adı gelir. Katılımcıları oradan toplarsın.

2) Kazananı seç

Adil ve güvenilir olması için
  • Seçim, tarayıcının güvenli rastgele sayı üretecini kullanır. Sonucu kimse yönlendiremez.
  • Çekilişi canlı yayında veya ekran kaydıyla yap, kazananı ve katılımcı sayısını paylaş.
  • Katılımı satın almaya bağlama ve kuralları baştan açıkça yaz. Çekiliş kurallarının yasal şartlarını bir yetişkinle birlikte araştır.
  • Katılımcıların tam isimlerini herkese açık paylaşma, siteye gizlenmiş hâli çıkar (örn. A*** Y***).

    GoatCounter panelini aç
    Kurulum (bir kerelik)
    1. goatcounter.com/signup adresinde hesap aç. Code kısmına bir ad seç (örn. yigityo3d). Siten yigityo3d.goatcounter.com olur.
    2. Giriş yap → Settings → Allow adding visitor counts on your website kutusunu işaretle, kaydet.
    3. Aşağıya seçtiğin code'u yaz, Kaydet'e bas. Site sayımı otomatik başlatır, başka bir şey yapman gerekmez.
    4. Kendi ziyaretlerini saymamak için, her cihazında sitenin adresinin sonuna #toggle-goatcounter ekleyip bir kez aç.

    Sayı "sayfa görüntülenmesi"dir (aynı kişi iki kez girerse iki sayılır). Ayrıntılı rapor (günlük, ülke, hangi site) için GoatCounter panelini aç. Sayı birkaç saate kadar geç güncellenebilir.
